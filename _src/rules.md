# 游戏开发规则与经验（通用版）

更新：2026-11-02 09:40 (Asia/Manila)　来源：数字门游戏（御剑斩妖录 / 星愿魔法少女）10-31 ～ 11-02 的开发过程
用法：做任何小游戏开工前先读「一、核心原则」，动手做某块时再翻对应章节；某个游戏的进度和数值看它自己的 CURRENT_STATE。
标记：不带标记的条目 = John 的要求或已确认做法，默认照做；【坑】= 真实踩过的坑；【做法】= 验证过的具体实现。

## 一、核心原则（每次改动都对照）

1. **难度曲线是核心**：挣扎 ↔ 割草交替；敌人只升不降，撑得越久越难，直到顶不住；允许倒下，但策略和操作拉满时理论上能一直赢。
2. **靠策略不靠手速**：每个选择都有取舍、没有永远最优解，几秒内能判断；不做赌博门；手上的技能不能“有啥扔啥”。
3. **看得过来**：节奏慢到能看清、能判断；弹窗来得及读；大事件先预告。
4. **看得见**：所有效果、成长、变化、压力都要在画面上看得到，并用一句话告诉玩家。
5. **不制造死局**：给出的机会要真的做得成，不能被别的东西挡住。
6. **界面不挡、不叠**：按钮和文字不挡人物和战场，屏幕元素之间也不能互相重叠；以手机竖屏 390×844 为准。
7. **一个东西一个名字**，换皮版本按自己的世界观用词，对玩家显示的文字不用英文。
8. **改了玩法就改说明**：新手引导、玩法说明、两个皮肤同步更新。
9. **说“做了”要有证据**：截图、模拟或线上核对；没实测的明说。
10. **多处同步**：每次改动同时更新 Claude 页面、网站、CURRENT_STATE。

## 二、玩法设计

### 难度与节奏
- 危险度用 0～100%（100% = 照这样必输）；不用技能要涨、用对技能要降、选错要看得出上升。
- 时间压力单独加（见四.时间压力），HUD 显示，倒下后回落一部分再继续涨；后期不能变成纯碾压。
- 一波压力之后的喘息至少是压力时长的 2 倍（割草 40 秒 : 妖潮 20 秒）；25 : 20 时玩家感觉“刚打完又来一波”。
- 关键时刻给喘息：破大境界自动放一次大招；斩大 Boss 后整顿几秒（停刷、回一点血、送好门）。
- 长线成长不能让单次收益显示成几乎为 0（如 +0.01 星）：小收益按“当前一级的百分比”显示，并配一个短周期的积累容器（聚灵瓶：约 8 次小收益装满、满了额外奖励），让零碎收益攒成看得见的奖励。先统计各来源占比（S.gsrc）再定。
- 改一波的时长后，按时间增长的难度（妖气）要同比调整，否则三选一 / 大招按时间变少，玩家相对变弱。
- 节奏放慢的标准做法：门按时间刷（收益不变）、怪少刷但更厚（压力不变），只改速度不改经济；改完跑模拟对比。
- 要有策略必须三件一起做：节奏慢到看得清；资源紧到放不完所有技能；放对了明显更值（对症克制 ×1.5 + 专属效果）。只放慢不收紧资源，照样一好就放。

### 选择与取舍
- 短期 vs 长期（只管下一波的限时加成 vs 越养越强的法宝）；安全 vs 冒险（直接拿的小收益 vs 要破锁的约 6 倍收益）；风险机会（天劫：不闯不罚但落后，闯成收益大，闯败有代价）。
- 三选一固定结构：短期 + 长期 + 常驻；满级后空位变“精进”（上限随境界）；流派专属选项混进对应位置。
- 不制造死局：怪潮前后不刷要花固定时间打的东西；要破锁的门同屏只出一个；大事件出现前先清空它所在的道。【坑】门会挡子弹，刷门要考虑火力路线。
- 主动技能每次释放都应是个决定：资源消耗、间隔、单发威力都要够大；总伤害按“每点资源的价值”保持不变。
- 大招按“当前火力 × N 秒”算伤害，不清屏，不能变成一键重置。
- 技能分层：短间隔小技能 + 中间隔控制 + 长冷却大招（限存量）；控制类即使用资源条也要保留较长的最短间隔。
- 门上直接写收益，带锁的门显示锁条；坏门要能躲，“全是坏门”时让玩家挑最轻的。

### 成长与收集
- 成长要看得见、有盼头：每个大境界形象明显更高级；提前一两个大境界预告大系统（如“到筑基选流派”），解锁清单和顶部目标都提示。
- 数值都跟境界挂钩；可无限叠的强化必须有上限且随境界提高，全满给替代奖励。
- 流派差异一上手就能感觉到、大到改变玩法（×0.8 / ×1.4 这种玩家感觉不出）：
  - 体修：堆数值硬推、更抗打，有被动、升级和大境界进化。
  - 法修：随境界转型——普攻占比逐步降到 ×0.1，靠资源条施法 + 自动释放的被动法术；后期可以站左道吃门。
  - 配合看得见的标志：专属按钮、资源球、流派形象、选流派动画、暂停页“输出构成”。
- 技能变多时不加按钮：大境界进化把原按钮升级换名。
- 长期养成要有足够级数：做到 20 级、每个大境界上限 +1；前几级大步后面小步；关键本事放固定级数（8 / 14 / 20）解锁并写在卡片上。
- 长期货币要有长期用途（如灵宠：不封顶、价格逐级上涨）；花钱买的成长不算进敌人强度，难度导演也不看它的击杀。
- 法宝 / 长期选项的卡片写清“下一级效果 + 满级效果”。
- 收集单位可自由收集、各自培养、上场带一只、任何流派可带；辅助单位要自主找目标出手（找目标 → 过去出手 → 回到身边，画面上看得到），不同物种打法不同。
- 商店价格要和收入匹配：新手第一局买得起前几级，越往后一级要打一整局；收入大改后回头核对价格。

### 敌人
- 敌人种类随进度变化：每几个大境界换一批外形和名字，每一阶还要有看得见的新本事（分裂、猛冲、狂暴、吞噬、催怪、护罩回血等），脚下标阶数、触发时飘字。
- 法修要有对症克制（每种本事一个应对法术，按钮发光提示）；体修靠数值硬推。
- 新敌人第一次出场前暂停介绍：是什么、本事、以当前实力几秒能打掉、威胁高低、按当前流派给打法；每存档每种只介绍一次，可关；不受“跳过全部引导”影响。
- 怪物技能要能读、能反制：读条可打断，一次只挂一个减益；每种波次特色都有对应的克制选项。
- 被动输出对 Boss 只打很小比例，Boss 和大波要玩家主动出手；Boss 冲线代价写在 Boss 身上。

### 信息与反馈
- 自动触发的效果：专属特效 + 结果文字（“收 5 只”）+ 常驻图标显示等级和冷却。主动技能按下立刻有反馈；没目标或资源不够要提示原因。
- 有变化就告诉玩家：进新大境界 / 换背景用一句好看的话说“来到了什么地方”；敌人换批也要说。
- 大事件提前约 6 秒预告（John 实测 10 秒太长，提前太久反而忘；12 秒更不行）：在它要出现的位置亮提示 + 倒计时 + 一句怎么准备；预告时间按真实出现时间推算（考虑妖潮、清道等延后），亮满才出现，不能预告了又不来。
- 特效不能大到挡住敌人（贴图特效缩到约 55% 并半透明）。
- 画面“太花看不清”的标准解法：背景柔焦 + 降饱和（缓存一次）；角色贴纸描边，敌人深色、自己和宠物浅色，敌我一眼分开；数字飘字画在特效上面；同句飘字合并、挨近的往上让、0 值不飘。
- 移动要有手感：按下处出现浮动摇杆圈（只显示方向，仍是相对拖动，不用推杆控速，那样选门不准）；灵敏度够高（手指划约半屏横跨两道）；移动时倾斜 + 拖尾；顶到边后反向立即生效。
- 音效用真实录制的 CC0 素材（Kenney、sfx-kit 等，GitHub 上可直接 clone），统一峰值后按事件混音；纯代码合成（哪怕做了音色库）John 听着“low”，只作加载前兜底。
- 音效不用单个振荡器“哔”：开声音时一次合成一套音色缓冲（拨弦、钟、鼓、噪声扫频等），总线压缩 + 混响，按事件命名调用，每种限频限并发；连杀沿五声音阶升调。两套皮肤各一套音色。
- 按来源统计伤害（约 1 分钟指数衰减），暂停页显示“输出构成”：给玩家看，也是调平衡的仪表。
- 图鉴做成功绩墙：每类都有图，得到的显示图和次数、没得到的显示剪影；分类用按钮切换（写收集进度），子类再加一排子按钮，不要长列表往下滑；点开看大图和详情。

### 界面
- 所有“跳过 / 不再显示”按钮必须显眼：大号、金边、带 ⏭ 图标，放在弹出内容的正下方；John 反映过找不到跳过。
- 重要操作（放技能）要有短暂时停 + 过场动画让玩家看清干了什么，并提供“以后不播”。过场美术优先拼现有立绘和特效图。
- 换素材目录跑 prep.py 时，清单必须保留已处理过的旧图（11-02 曾差点把 364 张图从清单里丢掉）。
- 【必查】每出现一个新概念（如聚灵瓶），先看原有界面和美术能不能改一改接着用；不能用就重新做界面、出手绘美术，不用代码画的圆圈凑数。John 已为此提醒过。
- 升级必须看得见：有等级的东西按阶段换名字、换样子（按钮边框 / 角标 / 身上特效 / 身边小伙伴），进阶时弹字加音效；被动尽量直接表现在人物身上。
- 【必查】任何新加的列表或模块，先对照本节：混了不同性质的东西（永久加成 / 装扮 / 消耗品）或超过一屏，一律用按钮分类（大类一排、子类一排小按钮），不接在旧列表下面往下滑。John 已为此提醒过多次（图鉴、商店）。
- 按钮全部放在防线和人物下方；新增按钮时整体重排，多了改多列缩小，不往上叠；标题和文字不压人物脸。
- 同时可能出现的屏幕文字（弹字、横幅、引导按钮、顶部状态）各占固定高度，不共用位置；会换行的按钮用 inline-block / flex 加间距。
- 多点触控：第一根手指控制移动，其他手指不干扰；技能按钮按下即生效。

### 换皮版本（同一玩法多套皮肤）
- 只换美术和文案；按这个版本的世界观逐词、逐句过一遍，不只做字面替换：名字贴合世界（敌人是噩梦 → “噩梦暂停”）；称呼符合受众口吻（功绩→勋章、符→贴纸、劫→考验、境→称号）；狠词换软词（烧死成灰→变成小花、狂暴→发脾气、吞噬→偷吃、血→体力）；套话整句换（九层圆满、这一方天地、“再降”、“第 N 境”）；不用英文（Boss → 大妖 / 大噩梦）。
- 换皮版如果重写了某个画面函数（如 draw），主版本以后在该函数里加的东西（特效贴图、登场大字等）不会自动进去：主版本每改一次画面函数，同步检查换皮版的那份；验收时两版同一场景并排截图对比。
- 检查方法：在浏览器里导出运行时所有对玩家显示的文字（技能、三选一、商店、说明、情报、引导、怪名、地名、飘字），按“残留词 + 狠词”清单扫一遍再逐条读；不能只扫源码（源码里大量被覆盖的文字不显示）。
- 换皮版单独写的说明会随主版本过时：改主版本说明时同步检查换皮版那份。美术同理：主版本补了图，换皮版逐项对照补齐。

### 长线与存档
- 可以设计成十几到几十小时，前期快后期慢；必须能随时存档退出、下次原地接着打。
- 气血会掉、会回，原因玩家看得懂，不偷偷回满。
- 倒下不清档：带着数值回到之前某一波重来（敌人按当时强度，再逐步追回），也可以结算；排行榜显示倒下次数，“一次没倒”单独标出。

## 三、新手引导与玩法说明

- 玩家不看字：一次只教一个概念，在“不得不用”的时刻教，必要时刻意制造场景（教大招就刷一大波怪、教清列就让一列堆满）。
- 一看就懂的只教 1 次；要练时机的最多 3 次，同一项间隔 ≥45 秒；跳过分「跳过这项」和「跳过全部引导」。
- 主动引导玩家注意技能按钮，教小技巧（技能快好时先放再吃补技能的门＝白用一次）。
- 实质更新时：新增或改写说明、补引导时机、删掉过时说法，两个皮肤都核对；老玩家已看过的说明要换新 key 再弹一次改版说明。
- 【做法】慢动作 + 聚光圈 + 等玩家点，比文字卡片有效；教学场景里漏怪不扣血；引导文字一行 ≤15 个汉字。
- 【做法】大事件（选流派）用近乎静止的慢动作 + 全屏动画 + 大字，相关说明等动画结束再弹；主页入口加状态提示（「灵宠 · 可收服」）比弹窗更不打扰。
- 【坑】引导依赖要分清“出现过”和“已教完”，否则改成多次引导后后续教学会卡住。
- 【坑】通用引导会抢掉具体引导：灵脉第一次出现被通用的“先把锁打开”抢走，从没讲过为什么要吃。具体系统的引导要排在通用引导前面。
- 有风险取舍的东西（灵脉 vs 聚气丹、天劫）必须讲“为什么值得 + 什么时候不值得”，并用当场的实际数字（这扇顶旁边几倍），不能只教怎么操作。

## 四、数值底层（可复用算法）

- **敌人强度**：参考火力 = 实际火力 × (应有配置 / 实际配置)^a（现用 a=0.25，即跟随实力的 0.75 次方）；每秒涌入怪物总血量 = 目标压力 × 参考火力，割草期低、怪潮期高、后期上限约 ×1.5。
- **时间压力（妖气）**：相对难度会把“越久越难”完全抵消，所以敌人血量另乘 1.1^(存活分钟)（复利）；危险度半分钟均值 <30% 时 3 倍速、<50% 时 1.8 倍速（越轻松涨越快）；倒下后分钟数减半；新手期最多 0.8 倍速。线性加成追不上养成，必须复利 + 按舒适度加速。
- **难度导演**：怪长期死在屏幕很靠上时小步加强（每阶段有上限）；被压到防线附近回退约 7%，倒下回退约 15%。门槛别太严，否则后期纯割草。
- **怪潮加码**：怪潮中每 0.5 秒看预测损失，不够紧张就小幅加厚（有上限），结束归零。
- **危险度** = 已损失 + 屏幕上必漏怪的预测损失 + 近期损失趋势 + 怪死得离防线多近（少了最后一项大部分时间显示 0%）。
- **进度**：用“每个境界目标时长表”统一缩放所有成长和损失，硬编码的固定扣减一起缩放；瓶颈期敌人成长放慢，防死亡螺旋。
- **血量**：伤害按占最大血量比例设计，前期打折后期全额；回血只来自看得见的事件。
- **技能定价**：伤害 = 消耗资源 × 每点资源对应几秒基础火力；调平衡只改一个效率常数；改手感（贵而重 / 便宜而轻）只改消耗和间隔。
- **倒下重来**：每波记检查点（敌人强度倍率）；重来时敌人乘“当时 / 现在”，约原耗时 60% 内按指数追回；期间导演不加压。
- **不算进敌人强度的成长**（灵宠）：价格指数涨、战力线性涨，长期对数增长，不会失控。
- **扩级不改公式**：另存原始等级，折算成旧效果等级（前 2 级 1:1，之后每级 1/6）写回原字段；旧存档按反函数换算。改永久数值时旧存档补一次换算（记版本标记）。
- 【坑】流派倍率算进参考火力 → 敌人同步变强，玩家感觉不到差别；流派倍率要从敌人参考和技能基准里剔除，单独乘在玩家输出上。
- 【坑】所有“看玩家多强”的系统都要计入新输出来源（法术、被动、灵宠）；法术击杀按“至少 30% 高度”计；锁门厚度按真正能打到门的火力定。
- 【坑】多个成长乘数叠起来后期爆炸、前期偏弱：每个乘数单独要小，用分境界模拟看两头。
- 【坑】“永不下降的参考值”在玩家暂时变弱时越打越难；按秒数增长的刷怪 / 加速必须设上限（如 300 秒后不变）。
- 调难度要分流派各跑一遍，针对性调该流派的判定，不整体放水。

## 五、技术实现（网页小游戏）

- **架构**：单文件 HTML + canvas，手机竖屏优先，逻辑在一个闭包里。多皮肤用构建脚本生成：有序替换表（长词在前、每条断言次数，新功能的替换放最前面单独表，皮肤专属收尾替换放最后），注入主题 JS/CSS，构建后扫残留词。
- **素材**：art/*.webp 单独放，游戏里有清单，有图用图、没图用代码画；文件名加皮肤前缀（g_）；?v=内容哈希防缓存；Claude 页面发布时用 files 带上新图；背景上叠一层淡色或深色遮罩保证可读。
- **发布**：一个部署脚本同时更新 Claude 页面和网站；网页打开时查 version.json 自动刷新。
- **托管**：GitHub + Cloudflare Pages（自有域名，子域名用 _middleware.js 分流）；Supabase（昵称 + 密码转假邮箱、关邮箱验证、表开 RLS 写明 grant、SQL 追加记录到 supabase.sql）；anon key 可公开，service_role key 永不读不存；免费项目用 GitHub Action 每 3 天 ping 防休眠。
- **国内玩家**：*.supabase.co 可能被拦 → 自有域名下 /sb/ 转发口（只放行 auth 和 rest）；外部字体非阻塞加载、第三方脚本放同一网站；能否打开必须请国内的人实测。公开给陌生人：限量名额（服务器触发器）、排行榜服务器端防改分、昵称过滤、云同步降频；昵称转邮箱限长 ≤64 字节；排行榜加字段时客户端要能在服务器没加列时自动去掉重试。
- **存档**：只存纯数据（不存怪、子弹、粒子），恢复时从下一段割草期开始；定时、切后台、关网页都自动存。游戏结束 / 存档退出 / 死亡面板弹出时清掉引导和弹窗。
- 【坑】一帧报错整个游戏卡死：每帧先预约下一帧，整帧逻辑包 try/catch。
- 【坑】行中间插 `//` 会注释掉后半行，补丁注释一律用 `/* */`，改完必须跑报错检查。
- 【坑】文字替换连锁误伤：短词吃长词、替换结果被后面规则再替换、新词撞旧词、带空格的字（“灵 宠”）漏网。每加一条都在两个版本里抓文字核对。
- 【坑】主题注入不能给 const 重新赋值，只能改函数或对象内容；皮肤里的境界名用境界表动态拼，不写死。
- 【坑】元素自身 display 会盖掉 hidden：全局加 [hidden]{display:none!important}。
- 【坑】查表前先判断键存在；“只触发一次”的标记要绑定上下文（如属于哪个境界）。
- 【坑】多点触控代码有了不等于真机能用：viewport 禁止缩放、按钮区 touch-action:none、拖动被系统取消后自动接回，并用 CDP 两指触摸实测“拖动中点按钮”。
- 【坑】补丁脚本最后才写文件时，中途断言失败会整份没写进去：失败后先确认文件状态再重跑；后台模拟要在补丁写入后再启动。

## 六、验证方法
- 多个限制条件叠在一起（时间窗、同屏只许一个、权重）时，要实测各类东西实际出现的比例（无人操作跑 10 分钟计数），不能只看权重：灵脉 / 符箓曾因“妖潮前 12 秒到妖潮结束不出 + 同屏只许一扇锁门”叠加，只占左道 4%，玩家觉得左边全是聚气丹。

- **发布前必做**：两个版本截图核对（手机宽度 390px）、无脚本报错、跑一次开着引导的模拟、核对玩法说明覆盖本次更新；上线后在线上抽查关键文字和版本号。
- **模拟**：Playwright 直接调用 update(dt) 加速；用 window.__X 钩子暴露内部状态，造场景、强制触发、截图。机器人多种策略（会选、乱选、不用技能、指定流派），记录每分钟境界、危险度、血量、实力比、输出构成、倒下次数；遇到死亡面板自动选一项。
- **验收“有难度但能赢”**：会选的机器人危险峰值 0.5～0.9、气血明显起伏但不死；乱选的会倒下并能追回；40 分钟长跑峰值长期低于 0.4 就说明后期没挑战。关键结论至少跑 2 局；流派设计用“用技能 vs 不用技能”对照；后期用“跳境界”起跑再跑 10 分钟（偏理想）。
- 调平衡要整体看：每次改完都重跑模拟，前期尤其要看。
- 机器人测不出体感（流派区别、选择是否做得成、按钮挡不挡、技能值不值得按），也不会闯天劫、反应偏快；几十小时后期只能推算——这些要从玩家视角逐个检查，并告诉 John 哪些是推算。
- 【做法】本地测试用 http 服务器（file:// 下带 ?v= 的图会失败），测试页补 <meta charset="utf-8">；并行模拟每个进程用自己的临时 HTML，2 核机器一次最多 5～6 局。

## 十、界面通用规则（11-02 19:44～19:55 John 定）
- 凡是能上下滑的页面，返回键固定悬浮在顶部（固定栏：返回键 + 标题），内容整页在下面滚，返回键永远看得见；不要在页面里再套一个小滚动框。新页面一律照做，不等 John 提醒。
- 排行榜类列表分级显示：前三名明显突出（奖牌、放大、金银铜底），4～10 名稍作区分，其余普通；条数有上限（现为 50）。
- 主角永远要看得清：名牌、进度条放在头顶上方并按图实际高度算；飘字落在人物身上时自动挪到名牌上方；跟随的小伙伴放在身侧不横穿身体；光罩类特效画在人物身后。
- 粉嫩、浅色系皮肤：背景要压暗压淡（雾、路面色降低），人物身后加深色底光，靠“深底 + 浅色角色”拉开对比；贴纸描边只描实心像素（alpha>150），否则半透明光效会被描成一团白雾。
- 截图核对要等背景切换动画结束（约 2 秒）再看，否则看到的是过渡中的旧背景。
- 能自动化的“操作技巧”就直接做成自动（例：技能就绪时吃到补充道具就自动释放），不要做成教学让玩家去学；新加补给类道具都先想“满了会不会浪费”。
- 线上核对：version.json 会比页面本身先更新到各节点，核对时要直接抓页面内容找本次改动的代码，不能只看版本号；刚部署完抓到旧页面就隔几十秒再抓。

## 十一、难度模型（11-02 21:01 John 定）
- 怪物强度主要跟波数走：同一波谁来打都一样强，越往后固定数值一定膨胀；跟角色实力只挂一小部分（现为 30%）。不再做“怪物跟着玩家变强”的自适应（妖气、难度导演那类），否则排行榜和“回去割草”都没意义。
- 玩家靠技能、宠物、法宝、养成和回去重修解决撞墙；割草感来自平时清小怪和重修时打穿以前打不动的波。
- 重修让玩家自己选回到哪里，同时把后果算清楚（收益、实力、资源、花多久），让玩家自己算账；不替玩家做固定选项。
- 曲线来源：用机器人在旧版里长时间模拟（≥10 小时游戏时间）测出“平均玩家每一波的怪物强度”，再整体打折给真人留余地（一个常量好调）；超出模拟范围的部分标为外推、未验证。
- 新加的弹层必须登记进 OVS 列表，否则 show() 打不开（11-02 21:30 踩坑）。
- 11-03 重定：怪物强度＝平均玩家在第 w 波的火力 D(w) × e^GW(w) ×（你的火力 / 平均火力）^0.3。GW 是一张手调表（前期低、中期平一段、第 100 波后每波约 +2%），想整体更难/更易就改这张表；不再用旧的“机器人+难度导演”校准值（那是在灵宠 bug 下测出来的，后期偏厚）。
- 输出结构的目标（每次改数值都用模拟看“输出构成”）：普攻 + 主动技能占大头（≥60%），灵宠、法宝、被动这类自动输出只当帮手（≤30%）。自动输出一旦占八九成，就会出现“不按技能也能清屏”“我打不动它、它也打不动我”。
- 公式坑：skillPool(秒数) 的参数是“几秒基础火力”，函数里会再乘火力；调用方不能先乘一次火力（11-03 灵宠就是这么多乘了一次，后期伤害随火力平方涨，清屏）。
- 自动清怪不能按“只数”秒杀（如葫芦一次收 N 只），一律折算成“几秒火力”，否则后期怪再厚也没用。
- 难度验证：每次改动用机器人跑 90 分钟（法修用技能 / 法修不用技能 / 体修 / 体修满级灵宠），看三样：怪死在离防线多远（kd，0.2 以下＝还没露面就死了）、割草/妖潮压力、多久倒一次；法修不用技能必须明显比用技能差。

## 十三、战斗设计（11-03 00:53 John）
- 每个阶段的数值要标清楚：我方气血、普攻、法术伤害；每种怪的气血、物防、法防；大妖的气血和技能。玩的时候、调数值的时候心里有数（暂停页「数值一览」，点左上「第 N 波」直达）。
- 给玩家看的数字不能大到没感觉（11-03 01:18 John：37亿、159亿太夸张）。指数成长的游戏不要整体等比缩小（前期会变小数），改用比例尺或百分比：不要用比例尺、点数这类要玩家换算的单位（11-03 02:02 John：太绕）；直接写玩家能感知的结果：“普攻几秒打死”“一发能打死几只小妖 / 大妖的百分之几”“伤害约为普攻的 X%”，修为损失写百分比。
- 限时爆发技（如体修 ×2.2、×2）要检查它对固定血量目标（天劫锁、护盾）的影响：两个叠开会把按基础火力定的锁瞬间打穿，这类目标按开方或不计爆发。
- 伤害分物理 / 法术，怪分物防 / 法防：石甲物防高、咒怨法防高、噬元魔两样都有、护法给身边的怪加两种防御；不同流派、不同技能各有克制对象。
- 妖潮和大妖不一起上：妖潮混多种怪，大妖在妖潮退去后单独上场（这时不刷小妖）。
- 保护型怪（护法）不能刷太多（同时 1 只，妖潮 2 只），但不点掉它，周围的怪就很难打；要给点杀它的技能（掌心雷：伤害 ×2、破罩），这样才有策略。
- 大妖要有能放出来的技能，而且不是全都能打断：有的只能硬扛或开护盾（天威）；有的召唤给友军减伤的小怪（护法）。
- 流派要有体现特点的主动技能：体修／星弓系有短时间大幅加攻击（剑意沸腾 ×2.2）、大幅加攻速（疾风连斩 ×2）的爆发技。
