# 素材原图存档（art_src）

ChatGPT 生成的全部原图（原尺寸），转成 WebP（质量 90）存档，用于以后重新裁切、换尺寸或复用。
游戏里实际加载的是 art/ 里压缩过的小图；本目录游戏不会读取。

文件名 = 出图编号：
- H* / XR_<流派>_<境界>：修仙版主角；P* / PF*：修仙版灵宠；M* / MV_<族>_<阶>：修仙版小妖；B* / BS*：修仙版 Boss；BG* / BR*：修仙版封面与背景；FX*：修仙版特效；IC_*：修仙版图标
- GH* / GHR_<流派>_<称号>：女生版角色；GP*：萌宠；GM* / GV_<族>_<阶>：怪物；GB*：Boss；GBGc / GR*：封面与背景；GFX*：特效；GIC_*：图标
- 带 q / r 后缀的是重画版本，优先用 r，其次 q
